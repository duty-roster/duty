강조 검색 공휴일 ①② 다음날 07시까지 연장
"기록에 저장"을 누르면
  • 지금 보이는 근무표가 실제로 선 근무로 기록돼요.
  • 공정표는 저장된 기록만 세요. 생성만 하고 저장하지 않으면 공정표에 반영되지 않아요.
  • 저장한 날짜마다 각자의 야간 시간대(22–02시 / 힘든 02–06시)와 연장 횟수가 더해지고, 힘든 비율이 다시 계산돼요.
  • 같은 날짜를 다시 저장하면 새 결과로 바뀌어요(두 번 세지 않아요).
  • 다음 근무표를 만들 때 시작 인원이 이어서 자동으로 골라져요.
  • 휴가 반영까지 끝나서 근무가 확정됐을 때 저장하세요. 잘못 저장했으면 ⚙️ 설정 → "기록 바로잡기"에서 고칠 수 있어요.
"기록에 저장"한 근무만 보여요. 고칠 곳이 있으면 ⚙️ 설정 → "기록 바로잡기"에서 고칠 수 있어요.

인원 명단

주간 제외 0 · 야간 제외 0 · 강조 0
도움말
· "⋯"를 누르면 주간/야간 제외, 강조, 순번 이동, 삭제를 할 수 있어요.
· 주간 제외 인원은 주간 순번에서 빠지고, 야간 제외 인원은 다음날이 휴일인 밤에만 야간에 들어가요.
· 합류일을 넣으면 적응 기간(기본 4주) 동안 근무에서 빠지고, 끝나는 날부터 자기 순번 자리에서 자동으로 들어가요.
· 종료일을 넣으면 그 전날부터 근무에서 빠져요. 종료 후 "삭제"하면 기록은 공정표의 "지난 인원"에서 계속 볼 수 있어요.
휴가 기간 주간은 전부 빠지고, 야간은 마지막 날 밤부터 다시 들어가요.
토·일요일은 자동으로 휴일이에요. 평일 공휴일만 넣으면 돼요.
"주간+야간"은 근무↔휴무 경계에 09시 인수인계가 자동으로 붙고, "주간만"은 야간은 그대로 둬요.
하루 조정을 따로 걸어두면 그게 먼저 적용돼요.
아직 저장된 기록이 없어요. 근무표를 만들고 "기록에 저장"을 누르면 여기서 집계돼요.

힘든 시간대 = 02–06시. 이름을 누르면 그 사람 일정이 아래에 나와요.

저장 · 백업

데이터는 이 기기 안에 자동 저장돼요. 앱을 지우거나 기기를 바꾸기 전에 백업 파일을 받아두세요.

기록 바로잡기

저장된 기간
잘못 저장한 기간은 근무표를 다시 만들어 "기록에 저장"하면 같은 날짜가 새 결과로 바뀌어요.
